# Support

Use GitHub Discussions or an issue for usage questions, reproducible bugs, and feature requests. Include the action path, exact release or commit SHA, runner type, relevant inputs with secrets removed, and the smallest useful log excerpt.

For Contract Guard, Impact, or Runtime Verify account, environment, billing, token-scope, or approved-contract assistance, contact `contact@alconite.com`.

For Runtime Verify issues, include only the operation ID, contract path template, safe finding rule, Action version, and run ID. Do not attach target credentials, expanded URLs, response bodies, local filesystem paths, or unredacted runner diagnostics.

For Impact issues, include only the check ID, safe evidence/risk code, Action version, aggregate collection counts, and runner operating system. Do not attach project tokens, source files, complete reports, absolute paths, or unredacted runner diagnostics.

Security reports must follow [SECURITY.md](SECURITY.md) and must not be filed publicly.
